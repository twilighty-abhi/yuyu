Once your event is live, get the word out. Every event has its own link, and you can add a short link, rely on a tidy preview when the link is posted in chats and social media, and put a register button or the whole event page on your own website.

Make sure the event is live first: until then, guests who open the link see nothing. See [Publishing and visibility](/help/events/publishing).

## Your event link

An event's link is your organisation's address followed by the event's address, for example `/riverside-coders/spring-meetup`.

To copy it:

- On the event's **Overview** tab, the **Share** card shows the link. Choose **Copy link**.
- In the event header, choose the link button next to **View page**.

The copy buttons appear once the event is live. Before that, the **Share** card still shows the link, with a note that guests can open it once the event is published.

Who can actually open the link depends on **Who can find it?**. An invite-only event's link only works for people you invited.

## Short links

A short link is a compact address such as `/aB3x9Kq`, handy for posters, slides and QR codes.

<Callout kind="permission">

Owners and admins create and regenerate short links. Anyone who can open the event dashboard can copy one that already exists, once the event is live.

</Callout>

<Steps>

1. Open the event's **Overview** tab.
2. In the **Share** card, choose **Create short link**.
3. Choose **Copy short link** to copy it.

</Steps>

A short link:

- **Only works while the event is live.** For a draft or offline event, it behaves like a link that doesn't exist, so it never gives away a hidden event.
- **Keeps working if you change the event address.** It always points at the current one.
- **Still follows the event's rules.** Invite-only events stay invite-only.

To replace a short link, for example if it was shared somewhere it shouldn't have been, choose **Regenerate**, then **Regenerate** again to confirm. The old short link stops working straight away.

## Link previews

When you paste a live event's link into a chat app or social network, it shows a preview with the event's title, the start of its description, and an image with the title, your organisation and the date.

Invite-only, draft and offline events show a plain Yuyu preview instead, so their details stay private.

Search engines only list events that are live and set to **Everyone**.

## Put it on your website

<Callout kind="permission">

Owners and admins.

</Callout>

<Steps>

1. Open the event's **Settings** tab, or choose **Embed on a website** in the **Overview** tab's **Share** card.
2. In **Put it on your website**, pick one:
   - **A register button**: shows "Register for" and your event's title, and opens the event page in a new tab. Choose **Copy button code**.
   - **The whole event page**: shows the event page, including registration, inside your site. Choose **Copy embed code**.
3. Paste the code into your website's HTML.

</Steps>

Choose **Show code** under either option to see the code before copying it.

<Callout kind="note">

The whole event page only shows on websites that this Yuyu server has been set up to allow. If it appears blank on your site, use the register button, or ask the person who runs your Yuyu server to allow your website.

</Callout>

The embedded page follows the same rules as the event page: drafts, offline events and invite-only events don't show to people who can't see them.

## Change the event address

The event address is the part of the link after your organisation's address. Yuyu makes it from the title when you create the event.

<Callout kind="permission">

Owners and admins.

</Callout>

<Steps>

1. Open the event's **Settings** tab.
2. In **Event address**, type the new address. Use lowercase letters, numbers and single hyphens, 2 to 64 characters.
3. Choose **Update**.

</Steps>

<Callout kind="warning">

Changing the address breaks links you've already shared: the old address stops working. Short links keep working, so for an event you might rename, share the short link. Copy any website code again after changing the address.

</Callout>

Each address can only be used by one event in your organisation.

## Your organisation's public page

Your organisation's page lists all its upcoming events that are live and set to **Everyone**. Share it once and people can always see what's coming up. See [Organisation settings](/help/organisations/settings#your-public-page).
